SR1.1 Overview
This chapter contains instructions for the grant of the following resident visas:
Skilled Migrant Category (
SR3
);
Green List: Straight to Residence (
SR4
);
Green List: Work to Residence (
SR5
);
Care Workforce: Work to Residence (
SR6
); and
Transport Sector Work to Residence visa (
SR7
).
The Skilled Residence visas set out at (a)(ii) to (v) above are sub-categories of the Skilled Migrant Category.
Applications for Green List: Straight to Residence and Green List: Work to Residence visas are prioritised in the order of processing above other skilled residence applications.
Effective 09/10/2023
